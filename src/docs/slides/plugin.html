Installer le plugin Figma, une seule fois

1

Dans Lisio, page Exporter : Plugin Figma (.zip), puis décompresser.

2

Dans l’application Figma pour ordinateur : Plugins › Development › Import new plugin from manifest…, puis manifest.json.

3

Ensuite, il est dans Plugins › Development › Lisio.

Plugin de développement : il s’installe depuis l’application pour ordinateur, pas depuis le navigateur.

Faire la manipulation en direct, une personne à la fois si besoin. Le zip est aussi dans les fichiers du projet. Une fois les variables importées dans un fichier, elles s’utilisent partout, navigateur compris.
