Sous chaque page, les lois UX qui s’y appliquent : Fitts, Hick, Jakob, proximité… Un ✓ ou un ✕ quand Lisio peut les mesurer sur votre système.

Onglet Design system, sélecteur « Page ». Définitions : Jon Yablonski, Laws of UX, lawsofux.com.

Les pages sont dessinées uniquement avec le CSS exporté : si une couleur ou une taille change dans Lisio, elles suivent. Changer d’écran (320 à 1440 px) et de mode (clair, sombre) pour voir le comportement réel. Exemple de contrôle : la loi de proximité vérifie que l’étiquette est plus proche de son champ que du champ suivant.
