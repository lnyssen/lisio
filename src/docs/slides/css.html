Pour les développeurs : le même système en CSS

/* 1. Primitives */

--marine: #0D1D45;

--marine-600: #4E628B;

/* 2. Rôles */

--text-default: var(--marine);

--background-default: var(--blanc);

Par catégorie : couleurs, rôles, mise en page, typographie, accessibilité, composants, effets.

Prêt à l’emploi : une classe .t- par style, focus, liens, .btn, .field, .alert.

À la carte : tout le CSS, les variables seules, une catégorie, une ligne, ou le fichier lisio.css.

Page Exporter, carte CSS. Mode sombre : prefers-color-scheme ou data-theme. Le JSON suit le format des design tokens du W3C.

Extrait simplifié du CSS exporté avec la palette de l’équipe. Les composants ne pointent jamais vers une primitive : ils passent par un rôle. Même logique que dans Figma, avec les mêmes noms. Dans le tableau d’une catégorie, « var() » copie var(--nom) et « Ligne » copie la déclaration entière. Deux couleurs au même nom : la seconde reçoit -2.
