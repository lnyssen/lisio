Pour les développeurs : le même système en CSS

/* 1. Primitives */

--marine: #0D1D45;

--marine-600: #4E628B;

/* 2. Rôles */

--text-default: var(--marine);

--background-default: var(--blanc);

Quatre couches : primitives, rôles, layout, typographie.

Prêt à l’emploi : une classe .t- par style, focus, liens, .btn, .field, .alert.

Mode sombre : prefers-color-scheme ou data-theme.

Page Exporter, « Copier le CSS ». Le JSON suit le format des design tokens du W3C.

Extrait simplifié du CSS exporté avec la palette de l’équipe. Les composants ne pointent jamais vers une primitive : ils passent par un rôle. Même logique que dans Figma, avec les mêmes noms.
