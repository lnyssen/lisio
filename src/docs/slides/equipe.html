Notre règle : une seule personne exporte vers Figma. Les autres envoient un lien, elle compare avant de reprendre.

Pas de compte ni de serveur : les réglages vivent dans le navigateur. Un lien de partage contient tout le projet, donc toute personne qui a le lien peut l’ouvrir. La comparaison liste les écarts variable par variable et leur effet sur les contrastes, sans rien remplacer.
