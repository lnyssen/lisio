Si 700 sur 100 passe pour une couleur, il passe pour toutes.

La page Couleurs de Lisio décline chaque couleur. Main est la couleur saisie, entourée ici. Les nuances sont calées sur la clarté, pas sur un pourcentage de blanc : c’est ce qui permet d’avoir des nuances foncées lisibles même pour un jaune ou un turquoise.
