Corriger, ou Tout corriger

La couleur passe dans le design system, reliée à sa variable, dans la même famille. Ctrl ou Cmd + Z annule.

Ses limites

Fonds unis seulement. Dégradé ou image : « à vérifier ». Il change le texte, jamais le fond.

Résultats réels d’un test du plugin sur une maquette volontairement ratée, au niveau AA : 4 textes sous le seuil, 4 corrigés. Le plugin liste aussi les couleurs utilisées et signale celles qui sortent du design system. Pour le bouton bleu clair, la meilleure correction est souvent de foncer le fond : à faire à la main.
